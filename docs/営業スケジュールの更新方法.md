# 営業スケジュールの更新方法

**曜日ごとのデフォルトルールが自動適用**されます。
祝日営業・臨時休業・イベント出店など、通常と異なる日だけをファイルに登録してください。

---

## 更新ファイル

```
src/data/schedule.ts
```

---

## 通常営業の自動判定ルール（変更不要）

以下の曜日ルールが常時有効です。登録が不要な日はこのルールが使われます。

| 曜日 | 営業 | 時間 |
|---|---|---|
| 日曜 | 営業 | 11:00-18:00 |
| 月曜 | 休業 | — |
| 火曜 | 休業 | — |
| 水曜 | 営業 | 11:00-18:00 |
| 木曜 | 営業 | 9:00〜試運転 |
| 金曜 | 営業 | 11:00-18:00 |
| 土曜 | 営業 | 9:00〜試運転 |

---

## 例外だけを登録する

`schedule` オブジェクトに `"YYYY-MM-DD"` 形式のキーで例外日のみ登録します。

> **注意**: 日付は必ずゼロ埋め（例: 3月1日 → `"2026-03-01"`）してください。

---

## パターン別の書き方

### 通常と異なる時間で営業（祝日の月曜など）

```ts
"2026-05-04": { isOpen: true, hours: "11:00-18:00" },
```

### メモ付き営業（パン販売日など）

```ts
"2026-04-12": { isOpen: true, note: "パン販売日！" },
```

時間と組み合わせることもできます。

```ts
"2026-04-12": { isOpen: true, hours: "11:00-18:00", note: "パン販売日！" },
```

### 臨時休業（本来は営業日だが休む場合）

```ts
"2026-04-16": { isOpen: false },
```

### イベント出店（店名あり）

```ts
"2026-04-19": {
  isOpen: true,
  hours: "10:00-16:00",
  isEvent: true,
  eventName: "筑紫野マルシェ",
},
```

### イベント出店（場所も表示したい場合）

```ts
"2026-04-26": {
  isOpen: true,
  hours: "10:00-16:00",
  isEvent: true,
  eventName: "春のマルシェ",
  eventLocation: "筑紫野市中央公園",
},
```

## サイトへの反映のしかた

1. `src/data/schedule.ts` を編集して例外日を追記する
2. ファイルを保存してコミット・プッシュ
3. Vercel に自動デプロイされます

## 月次更新のタイミング

毎月1日までに翌月の例外日をまとめて登録しておくと運用がスムーズです。
通常の曜日ルール通りの日は登録不要です。
