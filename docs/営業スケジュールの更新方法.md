# 営業スケジュールの更新方法

月のはじめに1ヶ月分の営業情報を登録すると、サイトのヒーローセクションとアクセスセクションに自動で反映されます。

---

## 更新ファイル

```
src/data/schedule.ts
```

---

## 基本の書き方

`schedule` オブジェクトに `"YYYY-MM-DD"` 形式のキーで1日ずつ登録します。

```ts
const schedule: Record<string, DayStatus> = {
  "2026-03-01": { isOpen: true, hours: "11:00 - 17:00" },
  "2026-03-02": { isOpen: false },
  // ...
};
```

> **注意**: 日付は必ずゼロ埋め（例: 3月1日 → `"2026-03-01"`）してください。

---

## パターン別の書き方

### 通常営業

```ts
"2026-03-01": { isOpen: true, hours: "11:00 - 17:00" },
```

### 休業日

```ts
"2026-03-09": { isOpen: false },
```

### イベント出店（店名あり）

```ts
"2026-03-15": {
  isOpen: true,
  hours: "10:00 - 16:00",
  isEvent: true,
  eventName: "筑紫野マルシェ",
},
```

### イベント出店（場所も追加したい場合）

```ts
"2026-03-22": {
  isOpen: true,
  hours: "10:00 - 16:00",
  isEvent: true,
  eventName: "春のマルシェ",
  eventLocation: "筑紫野市中央公園",
},
```

---

## サイトへの反映のしかた

1. `src/data/schedule.ts` を編集して翌月分を追記する
2. ファイルを保存してコミット
3. デプロイする（Vercel等に自動デプロイが設定されている場合はpushするだけ）

---

## 表示のされ方

| 状況 | ヒーローバッジ | アクセス営業時間 |
|---|---|---|
| 通常営業 | 🟢 本日営業中 11:00 - 17:00 | 11:00 - 17:00（緑色） |
| イベント出店 | 🟢 イベント出店中 — 筑紫野マルシェ — 10:00 - 16:00 | イベント出店中 / 筑紫野マルシェ / 10:00 - 16:00（緑色） |
| 休業日 | バッジ非表示 | 本日はお休みです（グレー） |
| 未登録の日付 | バッジ非表示 | 本日はお休みです（グレー） |

---

## 月次更新のタイミング

毎月1日までに翌月分をまとめて登録してデプロイしておくと運用がスムーズです。
